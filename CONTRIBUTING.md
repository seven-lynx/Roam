# Contributing to Roam

Thanks for helping improve Roam.

## Before you start

- Read [CONTEXT.md](CONTEXT.md) for current project state.
- Read the subsystem docs that match your change: [web/README.md](web/README.md), [android/README.md](android/README.md), [extension/README.md](extension/README.md), or [supabase/README.md](supabase/README.md).
- Check [ROADMAP.md](ROADMAP.md) so you do not duplicate planned work.

## Working rules

- Keep changes focused and small.
- Match existing patterns in the touched subsystem.
- Do not add stubs, TODO placeholders, or temporary hacks unless explicitly agreed.
- Update the relevant docs when you change user-facing behavior.
- Avoid committing secrets or generated build outputs.

## Pull requests

- Summarise what changed and why.
- Mention any manual validation you ran.
- Call out follow-up work if something is intentionally left for later.
